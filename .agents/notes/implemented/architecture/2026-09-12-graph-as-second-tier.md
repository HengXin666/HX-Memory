# Agent Note: 图候选降为第二梯队 (补位不抢占)

Status: implemented

## Problem

上一轮把实体抽取接入写入路径后, 图检索第一次有了边可扩展。但实测暴露一个两难:

| 读数 | 指标 | 结果 |
| --- | --- | --- |
| 一 (全体 171 个 case) | R@1 图关 / 图开 | 0.690 / **0.313** |
| 二 (字面不可达的 case) | 命中 图关 / 图开 | 1/4 / **3/4** |

两个读数方向相反, 原因是**指标定义而非实现**:
读数一的 gold 全部字面可命中, 图召回的"主题邻居"无从加分, 却以同等 RRF 权重参与排名,
给主榜单条目二次计分, 把词面-only 的高分条目挤下去 (图候选的 gold 精确率实测仅 **8.5%**, 50/588)。
读数二的目标字面不可达, 图通道是唯一能拿到它们的路径 —— 它确实有价值。

因此"开 / 关"是错的取舍: 关掉丢掉读数二的能力, 开着承担读数一的代价。

## Decision

给图通道一个**独立配额的第二梯队**:

- `gatherChannels` 返回值新增 `tier2`: 图扩展不再进主榜单, 而是单独返回。
- `HybridRetriever` 新增 `graphTierQuota` (默认 3, 0 = 不追加): 主榜单按分数排好后,
  图候选**作为尾巴追加**, 只补位、不参与打分竞争; 重复项与已被演化链上溯解析过的项会跳过。
- 追加项的 `score` 记为 0 —— 它不在同一条相关性尺度上, 不应被下游误读为"同等相关"。

## Alternatives considered

**把图通道权重降到 0.05。** 实测无效: R@1 仍只有 0.607 (关闭是 0.690), 而召回增益也没保住。
降权只是让噪声一起下沉, 没有改变"它参与了同一尺度的竞争"这件事。

**只在其它通道全空时才启用图 (兜底)。** 能让 R@1 回到 0.690, 但会把"从命中种子出发召回
结构相关邻居"这项能力压缩到几乎不触发 —— 实测 171 个 case 里只触发 1 次。conformance 明确
要求这项能力存在, 因此不符合意图。

**按查询自适应决定是否开图。** 上一轮已实测否掉类似思路: 把查询按字面可命中性分桶后,
向量通道在任何桶里都不优于词面; 图通道同理缺少可用的判别信号。

## Consequences

同一批 case 上三个模式的对照 (`graphTierQuota` 行为):

| 模式 | 全体 R@1 | 全体 R@10 | 图专属命中 |
| --- | --- | --- | --- |
| 图关闭 | 0.684 | 0.947 | 0.250 |
| 图参与竞争 (旧) | 0.630 | 0.947 | 0.750 |
| **第二梯队 (新)** | **0.684** | 0.947 | **0.750** |

即: 读数一的代价完全消除, 读数二的收益完全保留。用真实评分器复核, 5 个变体中
C/E (含图) 与 B/D (不含图) 的分数**逐位相同** —— 说明图通道不再干扰主排序, 只在需要时补位。

## Testing

- `tests/s1/retrieval.test.ts` 新增两条: 字面命中永远排在图候选之前; 字面不可达的邻居仍被
  `graph` 通道召回且 `why` 可审计 (conformance 要求的审计性不被削弱)。
- 全量 `vitest run`: 96 文件 / 684 用例全绿 —— 含既有的 conformance 图扩展契约
  (它断言"邻居被召回并给出 why", 第二梯队仍满足)。
