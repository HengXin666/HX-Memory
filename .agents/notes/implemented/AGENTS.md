# AGENTS.md — implemented Agent Notes

这里的 Note 描述**已发布**的决策。遵守 [Agent Note 规则](../README.md); 生命周期结构由 `verify-agent-note-format` 强制。

## 让已实施的 Note 与代码保持同步

代码改路径、符号、默认值、机制时, **在同一改动里**把 Note 里对应的事实改掉。就地改写陈旧事实, 不要追加"变更历史"。

当一篇已实施的 Note 不太可能再指导后续工作时, 走归档流程 (移动目录 + 补 `Archived: YYYY-MM-DD`), 而不是继续维护它。

### 这不是"改写决策"的许可

只就地更新**事实落地情况**。推翻决策或推翻理由需要新写一篇并互相链接; 完全被取代的旧 Note 才能按 README 的合并规则删除。
